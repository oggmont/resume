### How to edit

The files in [scribus/](scribus/) are [Scribus](https://www.scribus.net/) documents (`.sla`), created with **Scribus 1.5.8**. Use the same version: newer releases (1.6.x) can open them, but saving in a newer version may make them unreadable in 1.5.8.

1. Install Scribus 1.5.8 (free, open source) from the [Scribus 1.5.8 downloads](https://sourceforge.net/projects/scribus/files/scribus-devel/1.5.8/).
2. Open the `.sla` file from the `scribus/` folder.
3. Double-click a text frame to edit its contents (contact info, experience, skills, dates). Each section and each date range is its own frame, so you can move or resize them independently.
4. Export with **File → Export → Save as PDF**, overwriting `oscar-gm-resume.pdf` in the repo root.
5. Update this README to match, then commit both the `.sla` and the PDF.
